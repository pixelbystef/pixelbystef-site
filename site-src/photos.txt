# ==============================================================
#  pixelbystef.com - which photo goes where
# ==============================================================
#
#  HOW TO CHANGE A PHOTO
#   1. Put the photo (a normal JPG export, any size) in the
#      _web_revamp/assets folder. The site shrinks big files for you.
#   2. Type its file name under the section where it should appear.
#      The order here is the order on the page.
#   3. Ask Claude to "publish the website".
#
#  OPTIONAL EXTRAS on the same line, separated by  |
#      file.jpg | description for screen readers & Google | caption
#   - Caption: the small name shown when you hover a photo.
#     If left out, it's made from the file name
#     (ryan-niamh-9.jpg -> "Ryan & Niamh"). Write  -  for no caption.
#   - Landscape photos automatically take up two columns in galleries.
#     Tip: count portrait = 1, landscape = 2. If the total divides by 3,
#     the last row of the grid is full with no empty gap.
#
#  Lines starting with # are notes and are ignored.
# ==============================================================
